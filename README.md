# Telecom Customer Churn Analysis Dashboard 📊

An interactive **Power BI dashboard** created to analyze customer churn and identify patterns in customer behavior, retention, and service usage.

## 📌 Project Overview

This project uses Power BI to transform telecom customer data into an interactive dashboard. The dashboard helps analyze customer churn and understand the factors associated with customer retention and loss.

## 🎯 Objectives

* Analyze overall customer churn
* Understand customer retention patterns
* Compare churn across customer segments
* Identify factors associated with customer churn
* Analyze customer and service-related trends
* Present key insights through interactive visualizations

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Visualization
* Data Cleaning & Transformation

## 📊 Dashboard Features

* Customer churn analysis
* Churn rate analysis
* Customer segmentation
* Service and customer behavior analysis
* Interactive charts and visualizations
* KPI cards for important business metrics
* Interactive filtering and exploration

## 🔍 Key Skills Demonstrated

* Data cleaning and transformation using Power Query
* Data modeling
* DAX calculations
* KPI development
* Interactive dashboard design
* Business data analysis
* Data visualization
